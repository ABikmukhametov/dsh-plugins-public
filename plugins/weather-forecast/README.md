# Погодный прогноз для DSH

Пакет добавляет один инструмент `get_weather_forecast(location, days)` для запроса текстового прогноза на русском языке через wttr.in. `location` принимает название города или трёхбуквенный код аэропорта IATA, например `Moscow` или `MUC`, как указано в [справке wttr.in](https://wttr.in/:help). Плагин передаёт местоположение сервису и не проверяет, что найденная геолокация соответствует нужному аэропорту. Четырёхбуквенные коды ICAO технически проходят как строки, но их разрешение сервисом не гарантируется. `days` принимает целые числа от 0 до 3: только текущая погода, сегодня, сегодня и завтра, либо три дня. Запрос идёт по HTTPS с заголовком `User-Agent: curl`; местоположение кодируется как один компонент URL. Сетевые ошибки, HTML и чрезмерно длинные ответы не выдаются модели как прогноз.

Параметр `traceRegistration` включён в комплектном `cordis.patch.yml` для учебного сценария. При создании агента Host пишет в журнал его идентификатор, полный список видимых инструментов, их число и схему погодного инструмента. Событие `agent/created` происходит до первого хода модели. Запись раскрывает состав инструментов, поэтому после сценария отключите параметр в настройке плагина.

## Сборка и установка

Из корня репозитория задайте `DSH_SOURCE_ROOT` как абсолютный путь к подготовленному checkout DSH `0.2.0-rc.2` и соберите пакет:

```powershell
$env:DSH_SOURCE_ROOT = '<путь-к-DSH>'
node plugins/weather-forecast/scripts/pack.mjs
```

Целевые проверки после сборки: `node scripts/typecheck.mjs weather-forecast` и `node --test plugins/weather-forecast/tests/weather.test.mjs`. Общий `scripts/test.mjs` запускает прежние три пакета из отдельного тестового checkout; погодный пакет тестируется без копирования файлов в DSH.

Задайте `DSH_HOME` как абсолютный путь к используемому дому DSH. Из каталога DSH установите локальный архив в Web профиль:

```powershell
$env:DSH_HOME = '<путь-к-дому-DSH>'
pnpm dsh plugin --profile web add '<путь-к-репозиторию>/plugins/weather-forecast/artifacts/abikmukhametov-dsh-weather-forecast-0.1.1.tgz'
```

Создайте пустой чат Web и проверьте запись `weather-forecast: before first model turn` в окне Host до отправки сообщения. Затем запросите прогноз и сравните состав с первым `request/header` на вкладке Trajectory. Удаление пакета: `pnpm dsh plugin --profile web remove @abikmukhametov/dsh-weather-forecast` с тем же `DSH_HOME`.

Если ранее установлена версия `0.1.0`, удалите только погодный пакет и установите архив `0.1.1`. Пересборка архива сама по себе не обновляет установленную копию. После установки проверьте, что остальные пакеты профиля остались включены.
