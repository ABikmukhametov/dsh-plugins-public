# @abikmukhametov/dsh-locale-ru

Пакет добавляет «Русский» в Settings → General → Language для DSH `0.2.0-rc.2`. Переключение, сохранение предпочтения и английский fallback выполняет штатный `LocaleRuntime`. После локальной сборки пакет устанавливается готовым архивом; установка не запускает сборку и не загружает переводы из сети.

## Сборка и проверка

Для разработки используется подготовленный checkout официального DSH версии `0.2.0-rc.2`; его повторная сборка для проверки словарей не требуется. Из корня каталога плагинов:

```powershell
$env:DSH_SOURCE_ROOT = 'D:\path\to\deepseek-harness'
node scripts/check.mjs
```

Проверка сравнивает переводы с английскими словарями выбранного DSH, проверяет сохранённый корпус и примеры, пишет `plugins/locale-ru/coverage.json`. Отсутствующий перевод допустим; пустая строка или другой набор `{placeholders}` отклоняются.

## Установка

Пакет рассчитан на DSH `0.2.0-rc.2` и использует уже подготовленный официальный checkout с зависимостями и сборкой; подготовка среды описана в [корневом README](../../README.md#подготовка-среды). Из корня каталога плагинов:

```powershell
$env:DSH_SOURCE_ROOT = 'D:\path\to\deepseek-harness'
node plugins/locale-ru/scripts/build.mjs
node plugins/locale-ru/scripts/pack.mjs
```

Задайте `DSH_HOME` как абсолютный путь к профилю нужного Host. Из корня checkout DSH установите готовый архив:

```powershell
$env:DSH_HOME = 'D:\path\to\dsh-home'
pnpm dsh plugin --profile web add 'D:\path\to\dsh-plugins-public\plugins\locale-ru\artifacts\abikmukhametov-dsh-locale-ru-0.1.2.tgz'
```

Перезапустите Web. Удаление: `pnpm dsh plugin --profile web remove @abikmukhametov/dsh-locale-ru` из того же checkout DSH с тем же `DSH_HOME`.

## Отключение и удаление

В панели Plugins выключите переключатель пакета `@abikmukhametov/dsh-locale-ru`. HMR удаляет русский язык и его словари без перезапуска страницы или Host; интерфейс выбирает доступный язык. Повторное включение восстанавливает сохранённый выбор `ru`.

Удаление убирает пакет из профиля. При замене установленной версии пакета DSH может потребовать перезапуск; это отличается от переключателя включения.

При переходе с прежнего имени сначала удалите `@toefl/dsh-locale-ru` той же командой `remove`, затем установите новый архив. Одновременно подключать оба пакета нельзя: они регистрируют один язык `ru`. Штатное предпочтение языка сохраняется в конфигурации профиля.

## Просмотр переводов

В [examples/dictionaries.ru.json](examples/dictionaries.ru.json) лежит форматированный русский словарь с локальными поправками, включая ключи, которых уже нет в DSH. В [examples/translation-map.json](examples/translation-map.json) для каждого действующего английского ключа показаны `en`, зарегистрированный перевод `ru` и `displayedInRussian` — результат выбора русского языка. Значение `ru: null` означает английский fallback. Файлы входят в устанавливаемый архив; для просмотра сборка не нужна.

Тексты показаны до подстановки параметров и объединения фрагментов интерфейсом. Например, `workspace.toast.stoppedAndArchived` заканчивается словами «Вы можете »: интерфейс добавляет к ним ссылки действий из соседних ключей.

Примеры генерируются из исходного словаря и английских словарей этого checkout. Их вручную не редактируют; после изменения источников обновите и проверьте:

```powershell
node plugins/locale-ru/scripts/examples.mjs --write
node plugins/locale-ru/scripts/check.mjs
```

## Устройство и источники

[Patch](cordis.patch.yml) добавляет одну строку Host-плагина. [Host entry](src/index.ts) обеспечивает обнаружение клиентского файла; [Client entry](src/client.ts) регистрирует словари и язык одной операцией `ctx.effect()`. Ошибка регистрации откатывает уже добавленные записи; выгрузка удаляет все принадлежащие пакету регистрации. Сервисы, настройки и HTTP-маршруты пакет не добавляет.

Основной корпус взят из `lib/locales/core.json` репозитория [GooDAnDReaDY/dsh-russian-lang](https://github.com/GooDAnDReaDY/dsh-russian-lang). Изученная версия источника, SHA-256 и проверяемая версия DSH записаны в [SOURCE.json](vendor/SOURCE.json), исходная копия — [core.json](vendor/core.json), исходное MIT-уведомление — [LICENSE.txt](vendor/LICENSE.txt). Runtime-код того репозитория не используется. [Локальные поправки](src/overrides.json) обновляют изменённые тексты DSH 0.2 поверх сохранённого корпуса; runtime, проверка и примеры используют одну [функцию сборки словарей](src/compose.mjs). Единственный пустой исходный префикс `chat.message.stepProcess.sharedPrefix` исключён из регистрации и получает английское значение.

Fallback проходит `ru/en` выбранного раздела, затем `ru/en` раздела `common`, затем показывает сам ключ. Отсутствующий русский раздел также использует английский. Исходные тексты сервера, пользовательские сообщения и ответы модели автоматически не переводятся. Счётчики сохраняют штатную пару `.one`/`.other`; расширенные русские склонения, исправление раскладки и типографика не входят в первую версию.

## Проверка браузера

После установки в тестовый профиль откройте Settings → General → Language, выберите «Русский», перезагрузите страницу и проверьте сохранение выбора. Отключение пакета через Plugins возвращает штатный язык; повторное включение восстанавливает русский.

Модель не получает от этого пакета дополнительных инструкций или инструментов.
