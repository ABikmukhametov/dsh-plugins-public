# @abikmukhametov/dsh-artifact-download

## Кратко

В Web-интерфейсе пакет добавляет кнопку «Скачать» к каждому файлу, который агент показал через `present`, и к выбранному файлу в правой панели ревью карточки «Изменено». Чтобы скачать изменённый файл, откройте карточку и выберите нужный файл в панели; отдельный вызов `present` не требуется. Кнопка работает без настольного приложения на Host и сохраняет файл через менеджер загрузок браузера. Пакет читает текущее содержимое исходного файла, а не снимок на момент изменения.

## Установка

Пакет рассчитан на DSH `0.2.0-rc.2` и использует уже подготовленный официальный checkout с зависимостями и сборкой; подготовка среды описана в [корневом README](../../README.md#подготовка-среды). Из корня каталога плагинов:

```powershell
$env:DSH_SOURCE_ROOT = 'D:\path\to\deepseek-harness'
node plugins/artifact-download/scripts/pack.mjs
```

Задайте `DSH_HOME` как абсолютный путь к профилю нужного Host. Из корня checkout DSH установите готовый архив:

```powershell
$env:DSH_HOME = 'D:\path\to\dsh-home'
pnpm dsh plugin --profile web add 'D:\path\to\dsh-plugins-public\plugins\artifact-download\artifacts\abikmukhametov-dsh-artifact-download-0.1.3.tgz'
```

Перезапустите Web. Удаление: `pnpm dsh plugin --profile web remove @abikmukhametov/dsh-artifact-download` из того же checkout DSH с тем же `DSH_HOME`.

## Как работает загрузка

Кнопка сначала отправляет `HEAD` на авторизованный маршрут `/api/artifact.download`, затем передаёт адрес браузеру для `GET`. Host по идентификатору сессии, номеру события и индексу находит файл в событии `deliverables/presented` или в сводке события `workspace/changes` и проверяет, что сейчас это обычный доступный файл. Относительный путь должен оставаться внутри рабочей папки сессии после разрешения ссылок; явно записанный абсолютный путь читается, если его допускает файловая система агента. Ответ содержит `Content-Disposition: attachment`; байты передаются ограниченными блоками без промежуточной копии и общего предела размера. Размер блока задаёт `chunkBytes` в конфигурации строки плагина; по умолчанию 65536 байт. Если `workspaceFiles.maxBytes` меньше, плагин уменьшает блок при чтении.

## Ограничения

Пакет не показывает файловый менеджер и не скачивает автоматически все изменённые файлы. Сводка `workspace/changes` доступна только пока сессия обслуживается текущим Host; после её утраты старое ревью не даст скачать файл. Если исходный файл удалён, стал каталогом или символической ссылкой, предварительная проверка показывает ошибку. Обнаруженное изменение версии во время передачи прерывает поток, и браузер может показать незавершённую загрузку; этот механизм не создаёт неизменяемый снимок файла при одновременной записи. Успешная предварительная проверка означает начало загрузки, а не подтверждение, что браузер сохранил файл целиком.
